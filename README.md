# 個人旅行工具

## 👉 打開網站：https://cozylikerosie.github.io/travel-tool/

在電腦上規劃行程，旅途中用手機查看行程和記帳，回來後在電腦看完整花費。
不用註冊帳號，資料只存在你自己的裝置上，不會上傳到任何伺服器。

---

## 使用說明

### 1. 出發前：在電腦規劃行程

1. 用電腦打開網站，按「建立第一趟旅程」。
2. 填寫旅程名稱、目的地、出發與回程日期；預算、同行者、備註可以不填。
3. 進入旅程後按「每日行程」，為每一天加入地點和抵達時間。
   - 可以貼上 Google 地圖的座標或電腦版網址，地點就會出現在地圖上。
   - 也可以只輸入地點名稱。
4. 在兩個地點之間選擇交通方式（電車、巴士、步行等）。

### 2. 把行程放到手機

1. 在電腦的旅程頁按「輸出行程檔」，會下載一個 `旅程名稱-行程.json` 檔案。
2. 把檔案傳到手機（AirDrop、雲端硬碟或通訊軟體都可以）。
3. 用手機打開網站，在首頁按「匯入行程檔」，選擇剛剛的檔案。
4. **iPhone 建議**：在 Safari 按「分享 → 加入主畫面」，之後從主畫面圖示開啟。
   這樣沒有網路也能使用，資料也比較不會被系統清掉。

> 出發前如果又改了行程，重新輸出、再匯入一次即可。手機上已經記的花費會保留。

### 3. 旅途中：用手機看行程、記帳

1. 進入旅程，按「旅途模式」。
2. 畫面會自動跳到今天，顯示當天行程和剩餘預算。
3. 在「記一筆花費」輸入金額、選幣別和類別，按「記錄到 Day N」。
4. 記錯了可以在下方的花費列表按垃圾桶刪除。

沒有網路時也能查看行程和記帳。

### 4. 回來後：在電腦看花費結果

1. 在手機的旅途模式最下方按「匯出花費檔」，把檔案傳回電腦。
2. 在電腦的旅程頁按「匯入花費檔」，選擇該檔案。
3. 「花費結果」會顯示總花費、預算剩餘、依類別和每天的加總，以及全部明細。

> 同一份花費檔重複匯入不會重複計算。

### 5. 旅程回顧：一頁看完去了哪裡、花了多少

1. 在旅程頁按「旅程回顧」。
2. 上方是總覽：去了幾個地點、總花費、預算剩多少、錢都花在哪些類別。
3. 下方依天列出：當天去的地點與時間、當天每一筆花費和小計。
4. 按「列印／存成 PDF」，在列印視窗選「儲存為 PDF」，就能把回顧存進電腦資料夾留念。

---

## 注意事項

- **資料只存在各自的裝置**：電腦和手機不會自動同步，要靠上面的檔案來交換。
- **清除瀏覽器資料會讓資料消失**：換手機或清快取前，記得先匯出花費檔備份。
- **不同幣別分開加總**：工具不做匯率換算，預算只和相同幣別的花費比較。
- **傳檔案時資料會經過你使用的服務**：例如 LINE 或雲端硬碟；介意的話可以用 AirDrop。

## 開發

```bash
npm install
npm run dev       # 本機開發
npm run test:run  # 執行測試
npm run build     # 建置
```

推送到 `main` 分支後，GitHub Actions 會自動部署到 GitHub Pages。
需求規格在 [`specs/`](specs/)，設計指南在 [`docs/design-guide.md`](docs/design-guide.md)。
