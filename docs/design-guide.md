# 設計指南

## 整體氛圍
參考日本生活風格雜誌的編輯美學：安靜、精緻、留白充足，像在翻閱一本旅行雜誌。
以文字排版建立質感，不依賴鮮豔色彩或裝飾。
（僅參考氛圍，介面中不使用任何雜誌刊名或標誌）

## 配色
- 背景：#F7F5F0（溫暖米白，像紙張）
- 卡片／區塊背景：#FFFFFF
- 主要文字：#1A1A1A（墨黑）
- 次要文字：#6B6B6B
- 分隔線：#D9D5CC（1px 細線）
- 點綴色：#8A7A5C（低彩度的沙金色，只用在少數重點，例如目前選取的項目）
- 預算狀態（保持低彩度）：
  - 充足：#6F8A6B（灰綠）
  - 接近上限：#B8935A（土黃）
  - 超支：#A65A4E（磚紅）
- 不使用鮮豔的飽和色

## 字體
- 中文標題：Noto Serif TC（襯線、明朝風格）
- 中文內文：Noto Sans TC，字重 400，行高 1.8
- 英文標題與數字：Cormorant Garamond（優雅的襯線體）
- 英文小標籤：Inter，全大寫、字級小（11–12px）、字距 0.15em
  例如在中文標題上方放置小標籤：ITINERARY／每日行程
- 金額使用等寬數字（tabular-nums），方便對齊

## 排版
- 大量留白：區塊之間至少 48px（電腦版）、32px（手機版）
- 標題字級明顯大於內文，形成雜誌式的層次
- 章節分隔使用 2px 墨黑粗線，章節內的欄位與項目分隔使用 1px 細線；不使用陰影
- 圓角很小（0–4px），保持俐落
- 日期採雜誌式寫法，例如大字的「12.20」加上小字的「SAT」

## 元件
- 主要按鈕：墨黑底、白字、直角或極小圓角
- 次要按鈕：無底色、細線外框，或只有文字加底線
- 輸入框：只有底線，不用方框
- 旅程卡片：白底、細線邊框，標題用襯線體，目的地用小號英文標籤
- 圖示：細線條風格（線寬 1.5px），例如 Lucide Icons

## 地圖
- 使用低彩度的灰階地圖底圖（例如 CARTO Positron）
- 路線與標記使用墨黑或點綴色，不用預設的藍色圖釘

## 電腦版 vs 手機版
- 電腦：寬版，可用不對稱的雜誌式雙欄排版
- 手機：單欄，保持留白，但重要資訊（今日行程、剩餘預算）放在畫面上方
- 手機按鈕高度至少 44px，方便單手點擊

## 可讀性底線
風格不能犧牲可讀性：
- 文字與背景的對比度需符合 WCAG AA
- 手機內文不小於 16px
- 在戶外陽光下也要看得清楚

## 深色模式
- 背景：#141414，文字：#EDEAE3，分隔線：#3A3833
- 維持同樣的低彩度與留白
